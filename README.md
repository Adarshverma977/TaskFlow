Getting Started

Prerequisites

Make sure you have the following installed:

* Node.js and npm
* MongoDB, locally or through a MongoDB deployment
* Git

Installation

1. Clone the repository

git clone https://github.com/Adarshverma977/TaskFlow.git
cd TaskFlow

2. Install frontend dependencies

cd client
npm install

3. Install backend dependencies

cd ../server
npm install

4. Configure environment variables

Create a .env file in the backend directory and add the variables required by your application.

Example:

PORT=5000
MONGODB_URI=your_mongodb_connection_string

Replace the example values with your actual configuration. Add other variables only if your code requires them.

5. Start the application

Run the frontend and backend using the scripts defined in their respective package.json files.

For example, if both projects use a dev script:

Backend terminal:

cd server
npm run dev

Frontend terminal:

cd client
npm run dev

Check your configured ports and API URLs if they differ from these examples.
